## 🔍 4. Рекомендации для твоего колена

### 🏋️‍♂️ Упражнения (основа — **нейромышечная стабилизация**):

1. **Hamstring curls (сгибания голени)** — укрепляют заднюю линию, которая берёт часть функции ПКС.
    
2. **Nordic hamstring** (нордические сгибания) — лучший вариант для контроля.
    
3. **Glute bridge / hip thrust** — мощные ягодицы стабилизируют таз и уменьшают ротацию.
    
4. **Single-leg balance + приседания на одной ноге** — тренируют **проприоцепцию** (ощущение положения сустава).
    
5. **Боковые движения с резиной (monster walk)** — держат колено «в линии».
    
6. **Приседания / становая** — только в **контролируемой технике**, без больших ротаций.
